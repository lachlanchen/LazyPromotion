一段粵語影片需要「繁體加簡體字幕」，不應該變成兩份各自修改的字幕檔。較穩妥的結構是：一條校對過的時間軸、一份繁體中文字幕、由它轉換並再檢查的簡體字幕，以及從同一份資料渲染出來的預覽片。

這樣日後修正會很簡單：改一條字幕，把修改帶到兩種字體，重新渲染，再核對真正要交付的檔案。

## 編輯前先保存來源

客戶提供的錄影保持不動，另做工作副本。記下原始檔名、時長、音訊語言、畫面尺寸和 SHA-256 雜湊，也要記錄素材由誰擁有，以及完成的字幕可以在哪裡發佈。

```bash
sha256sum source.mp4
ffprobe -v error -show_entries format=duration \
  -show_entries stream=codec_type,codec_name,width,height,r_frame_rate \
  -of json source.mp4
```

這份小帳本可以避免壓縮過的預覽片悄悄取代原始檔。幾星期後客戶要求修正時，也能照原本的流程重建成品。

## 先校對粵語字幕

自動語音辨識可以提供初稿，但繁體字幕仍要一邊聽原聲，一邊校正。聽不清楚就標成待確認，不要猜。人名、引文、數字和專業詞彙最好另列一張表。

如果內容是講座或講道，先問清楚講者採用哪個版本或術語表。句子即使耳熟，引用了不同譯本仍可能出錯。除非清楚標為編輯說明，否則不要把潤飾後的新意思塞進逐字稿。

字幕切點既要看停頓，也要看語意。如果把人名、數字或一個短短的否定詞切成兩條，即使時間碼形式完全正確，讀起來仍然很辛苦。

## 轉換字體後，再檢查用詞

[OpenCC](https://github.com/BYVoid/OpenCC) 可以確定性地轉換簡體、繁體、香港和台灣的字形與部分地區用詞。把香港繁體文字轉成簡體，第一步可以很簡單：

```bash
opencc -c hk2s.json -i captions-yue-Hant.srt -o captions-zh-Hans.srt
```

這是字體與地區用詞轉換，不是把粵語翻譯成普通話。OpenCC 的說明也清楚寫明：詞庫以官話詞彙為基準，不負責普通話與粵語之間的翻譯。人名、經文或技術術語、粵語助詞、引文和地區用詞，仍要對照原聲與目標觀眾逐項檢查。

不要為簡體字幕重新產生一套時間碼。兩個檔案應保留相同的字幕編號和時間範圍，這樣一次時間修正就只需要改一次。

## 兩個檔案共用一條時間軸

普通 SRT 的好處是容易查看。[YouTube 目前的字幕格式說明](https://support.google.com/youtube/answer/2734698?hl=en) 建議初學者使用基本的 SRT 或 SBV，並要求基本 SRT 使用純 UTF-8。一對四條字幕的檔案，差別應在文字，不在結構：

```text
4
00:00:18,020 --> 00:00:23,520
小小心仍輕輕顫抖
```

簡體檔仍然使用第 `4` 條和同一段時間，只把校對後的文字換成 `小小心仍轻轻颤抖`。

檢查第一條和最後一條、每次換講者、長停頓、快速段落，以及辨識器不確定的所有位置。如果合約訂明時間誤差，就要把畫面上的字幕進出點與實際發聲逐段比較。檔案解析器無法證明字幕是否在某個字說出口前後 0.2 秒內出現。

## 燒錄預覽片並實際觀看

[FFmpeg 的 `subtitles` 濾鏡](https://ffmpeg.org/ffmpeg-filters.html#subtitles-1) 透過 libass 渲染字幕，並支援額外字體目錄和明確的樣式覆寫。簡單的 H.264/AAC 核對片可以這樣製作：

```bash
ffmpeg -i source.mp4 \
  -vf "subtitles=captions-zh-Hans.srt:fontsdir=/usr/share/fonts/opentype/noto:force_style='FontName=Noto Sans CJK SC,FontSize=24,Outline=2'" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -movflags +faststart preview.mp4
```

用正常速度看完整段成片。檢查換行、標點、安全邊距、中文字體後備、剪接，以及字幕是否遮住人臉、投影片或原有畫面文字。之後再用 `ffprobe` 檢查，並為成品計算雜湊。FFmpeg 成功結束只證明渲染完成，不代表文字和時間都正確。

## 影片之外，也要交付可編輯檔案

一份小而實用的交付應包含：

- 校對完成的繁體中文 SRT；
- 時間一致的簡體中文 SRT；
- 內嵌指定字幕的 H.264 MP4；
- 記錄模糊音訊與術語決定的簡短問題表；
- 包含來源與輸出雜湊、時長、尺寸、編碼和工具的清單；
- 雙方約定的修正期限。

不要只交一段已燒錄字幕的影片。獨立字幕檔讓素材擁有者可以修改術語、上載可開關字幕，或換一種樣式重新渲染，而不必再轉錄一次。[LazyEdit](https://github.com/lachlanchen/LazyEdit) 是我用來處理這類來源優先字幕工作的開源流程。
