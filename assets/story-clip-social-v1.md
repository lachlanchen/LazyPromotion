# Story Clip service card

Source: `story-clip-social-v1.html`. Export: `story-clip-social-v1.jpg`.

This is an HTML/CSS diagram of the existing USD 250 service, not a video frame,
customer result, or performance claim. It replaces the dense website screenshot
only in the existing Instagram item. The separate Contra cover is unchanged.

The reviewed export is a 1080 × 1350 JPEG, quality 95, 140,262 bytes:

`c7a1c2cbd9787cfa7f93598ce3c4582d2d8d5aeecc98c675436e071cf6ddacfa`

To rebuild, serve this directory on localhost, open the HTML in the dedicated
project browser, set the viewport to 1080 × 1350, wait for `document.fonts.ready`,
and screenshot the `main` element as JPEG with quality 95. The page uses local
Georgia and Arial font fallbacks and no external assets. A different browser or
font installation may produce a different file hash; visually review any new
export before uploading it. Do not change the service scope when changing layout.

The September 13 review checked the full export and the saved Postiz preview:
the headline, selection flow, price, scope and sample URL were visible. Keep
the public sample as the proof destination; this card does not replace it.
