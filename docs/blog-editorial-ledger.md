## Evidence and privacy boundaries

- This ledger contains no credentials, cookies, Stripe data, private messages, browser profiles, or raw session history.
- The unrelated modified `content/chat/.../session.json` file in the BLOG worktree is never staged as editorial evidence.
- Live publication is not evidence of traffic, leads, customers, donations, or revenue. Those outcomes must be recorded separately from analytics, payment, or customer artifacts.
- No post is described as complete merely because a draft exists; live sync, REST verification, commit, and remote push are required.
