# Paid-need decision — 2026-09-13

One no-fee asynchronous route is stronger than another speculative service page.

Vetto's current [Senior Software Code Reviewer](https://job-boards.greenhouse.io/vetto/jobs/4112754009) listing asks reviewers to decide whether a task is well-defined, generated code actually solves it, and tests would catch a plausible but wrong implementation. It advertises approximately USD 100 per hour on a task-equivalent basis, with compensation varying by complexity and approved volume. Python plus JavaScript/TypeScript, open-source work, negative tests, Playwright/pytest evidence, and explicit false-success gates are publicly supported by the portfolio.

One factual application was submitted with a checked one-page resume. It described the work as agent-assisted, selected only Python and JavaScript/TypeScript, used scheduling-constraint availability, and made no claim of five-plus production years, native English, Go/Rust/Java proficiency, or unaided authorship. Greenhouse visibly confirmed receipt without a verification challenge. No exercise, identity check, contract term, task allocation, payment, or revenue followed.

A separate Freelancer RAG implementation brief matched Local Knowledge Terminal technically but did not pass the commercial gate. The authenticated page showed 119 bids and required a USD 20 account balance before bidding. No balance, skill change, upgrade, or bid was made.

## Decision

1. Monitor the Vetto application without proactive follow-up before September 20.
2. Review any technical exercise rules before starting; do not represent agent-assisted work as unaided work.
3. Keep the USD 500 MCP review as the primary owned offer and the existing no-fee applications as secondary acquisition routes.
4. Count nothing until accepted work, delivery, and payment are independently evidenced.
