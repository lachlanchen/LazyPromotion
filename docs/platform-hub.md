# LazyingArt product hub

Public hub: <https://platform.lazying.art/>

Source: <https://github.com/lachlanchen/LazyingArtPlatform>

The hub connects the existing app listings, handmade shop and useful product
stories without changing the stable main LazyingArt website or creating a new
checkout. The main site's product directory links to it as **Apps & shop**.
LazyingArt is the company brand; the platform has no personal founder byline.

## Customer paths

| Interest | Destination |
| --- | --- |
| L & N pronunciation/listening | Official Apple and Google listings plus the existing English walkthrough |
| Bunko classics | Official Apple and Mac listings plus the English walkthrough; no pending Google release claim |
| EchoMind conversations | Official Apple/Google listings and <https://chat.lazying.art/> |
| Handmade notebooks, dolls and pendants | Existing product selectors at <https://buy.lazying.art/>; existing Stripe checkout remains independently owned |
| Product stories | The existing blog, Medium and source repositories |
| Coin community | <https://coin.lazying.art/>; optional and separate from purchases |

The site uses project-owned app icons and the existing notebook photograph.
Public browsing needs no account. No sample balance, active airdrop, new payment
object or customer result is advertised. App availability and pricing should
be rechecked before later campaigns.

## Account integration — not live

Platform has a source-tested shared-account consumer and a separate source-tested
Coin-summary validator/renderer. EchoMind owns the identity service and provider
connections; Coin owns its resource authorization and personal-summary route.
The shared issuer, registered app client, actual provider callbacks, delegated
Coin-read consent and production qualification are still dependencies.

Do not turn source tests into a working-login claim. Current public browsing
continues through ordinary product links. Account credentials, customer data,
deployment receipts and owner coordination stay outside this repository.

Publication and new links are funnel infrastructure, not confirmed revenue.
