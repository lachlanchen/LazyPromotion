# Bilingual Lecture Pack sample

This is a project-owned, synthetic delivery sample for the [Bilingual Lecture Pack](https://lazying.art/lecture-pack/). It shows the files in the fixed pilot without using customer media or presenting a generated exercise as a customer result.

The English mini-lecture explains why provenance matters in a multilingual knowledge graph. Its narration is generated locally from the included script with eSpeak NG. The Traditional Chinese translation is assisted, terminology-checked, and aligned to the English timing; it is not a certified translation or an independent native-language review.

## Open the packet

- `artifacts/bilingual-lecture-pack-sample.zip` — deterministic delivery ZIP
- `artifacts/bilingual-lecture-pack-sample.zip.sha256` — pinned ZIP checksum
- `source/` — project-owned English script, generated WAV source, and source note
- `working/` — preserved first ASR draft used by the issue ledger
- `delivery/transcript/` — corrected timestamped English Markdown
- `delivery/subtitles/` — corrected English and Traditional Chinese SRT files
- `delivery/aligned-source.json` — editable bilingual segment source
- `delivery/study-companion/` — editable TeX and A5 PDF
- `delivery/preview/` — 40.88-second H.264/AAC bilingual-caption preview and poster
- `delivery/issue-ledger.md` — corrections and review boundaries
- `delivery/manifest.json` and `delivery/SHA256SUMS` — rights, provenance, inventory, and file hashes

## Rebuild

Run `./build.sh` on a system with eSpeak NG 1.51, FFmpeg 6.1, XeLaTeX/TeX Live 2023, Noto Serif CJK TC, `jq`, `zip`, and standard checksum tools. The script regenerates the audio, PDF, video, poster, manifests, and ZIP from the editable source files.

The captured ASR draft is evidence from OpenAI Whisper `tiny.en` (`openai-whisper` 20250625); it is deliberately not regenerated by the build because model and hardware changes can alter decoding.
