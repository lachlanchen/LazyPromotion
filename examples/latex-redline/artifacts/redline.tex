\section{Method}

A manuscript revision should freeze complete old and revised source trees and
build each one independently. \DIFdelbegin \DIFdel{The checked comparison }\DIFdelend \DIFaddbegin \DIFadd{It should then generate the redline from those
exact snapshots. The checked revision }\DIFaddend state is represented by

\begin{equation}
  R = (S_{\mathrm{old}}, S_{\mathrm{new}}\DIFaddbegin \DIFadd{, D}\DIFaddend ),
  \label{eq:build-state}
\end{equation}

where the two $S$ terms are named source snapshots \DIFaddbegin \DIFadd{and $D$ is the generated
diff source. Each source is }\DIFaddend compiled with the same engine and dependency set.
