\section*{Review states and offline boundary}
Provenance edge states are observed, inferred, and reviewed. Inferred edges
must never be rendered as if they came directly from a source passage.

An offline rebuild uses only the source ledger, extracted pages, fixed lexical
settings, and the saved question set. This synthetic note supports a bounded
multilingual extraction check, not a whole-collection knowledge graph.
